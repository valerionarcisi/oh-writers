BIB-03 · GlobalContext memo 60s
5 call consecutive → 1 sola query DB

Cross-cutting · Spec 38+40
Scene Summaries
Generazione Haiku fingerprint-guarded. Finestre di rilevanza per page type (spec 40).
Verifica summaries nel DB SELECT number, scene_summary IS NOT NULL as has_summary FROM scenes WHERE screenplay_id = 'ID' ORDER BY number;
SUM-01 · Generazione al salvataggio
Modificare e salvare una scena → summary si aggiorna
Dopo il salvataggio (debounce ~2s), la colonna scene_summary nel DB si aggiorna. Un secondo salvataggio identico non genera una nuova call Haiku (fingerprint check).
SUM-02 · Finestra rilevanza locations
Locations: carica solo summaries scene collegate al requirement
Con log in buildLocalContext: le scene caricate nei summaries sono solo quelle del linkedSceneIds del requirement aperto. NON tutte le scene del progetto.
SUM-03 · Budget nessun summary
Budget page non carica summaries (by design)
Con log: sceneSummaries.length === 0 sulla pagina budget. Il budget non ha bisogno di contesto scena — è corretto.

Spec 37 · Location UI
Discovery area
Confine comune → pin scoperti (cerchio blu) via Google Places. Clustering automatico sopra soglia 20 pin.
D37-01 · Comune → confine + pin
Cerca "Fermo" → confine del comune + pin scoperti
Confine del comune di Fermo (non della provincia). Pin blu vuoti dentro il confine. Banner "Nessun candidato in: Fermo".
Confine enorme (provincia intera) = bug tranello capoluogo.
D37-02 · Aggiungi pin come candidato
Cliccando un pin scoperto → popup → "Aggiungi come candidato"
Popup mostra nome, indirizzo, chip "→ adatto a: [fabbisogno]", bottone "+ Aggiungi". Cliccando: conteggio candidati +1, persiste al reload.
D37-03 · Clustering città grande
Milano/Roma → pin si raggruppano in cluster numerati
Zoom indietro: pin collassano in cerchi con numero. Zoom avanti: si spezzano. Click su cluster: mappa zooma sui suoi pin.
Con ≤20 scoperte nessun cluster — corretto.
Spec 37b · Location UI
Discovery per scena
I pin cambiano in base al tipo del fabbisogno selezionato. Foto nel popup, "Rimuovi area", ricerca manuale libera.
S37-01 · Pin cambiano con il fabbisogno
Selezionare fabbisogno diverso → pin diversi
Fabbisogno "Ristorante - Forno" → pin ristoranti. Fabbisogno "Bancone" → pin bar/pub. Fabbisogno "strada" → nessun pin (tipo non cercabile).
S37-02 · Foto, rimuovi area, ricerca libera
Popup mostra foto · "Rimuovi area" pulisce · ricerca manuale funziona
Foto nel popup. "✕ Rimuovi area" cancella confine + pin. Disegna cerchio → "Cerca in questa area" → digita "pasticceria" → risultati con miniatura + "Aggiungi".
Spec 37c · Location UI
Ranking atmosfera
Cesare ordina i pin scoperti per adattabilità all'atmosfera della scena selezionata. On-demand: una call AI per click.
A37-01 · "Ordina per scena" riordina i pin
Il bottone appare con scena + pin attivi, riordina, aggiunge commento Cesare
Bottone "✦ Ordina per scena" visibile solo se scena selezionata + pin scoperti presenti. Click → "Ordino…" → pin riordinati. Popup ogni pin: riga di Cesare con spiegazione atmosfera.
Il bottone non appare senza scena selezionata o senza pin — corretto.
